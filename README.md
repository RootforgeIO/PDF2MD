# PDF2MD

Локальное приложение для Windows: **PDF, Word, Excel, CSV, TSV и TXT → Markdown**. Сохраняет результат отдельным файлом, извлекает текст, таблицы и изображения. Интерфейс — на русском и английском.

Программа создана для подготовки документов к работе с ИИ: Markdown помогает сократить расход токенов на их обработку. Фактическая экономия зависит от документа и используемого ИИ-сервиса.

## Быстрый старт

1. Установите программу или полностью распакуйте portable-архив.
2. Запустите **PDF2MD**, нажмите **Обзор…** или перетащите документ в окно.
3. Для Excel выберите лист. Для PDF оставьте движок **auto** или выберите его вручную.
4. Нажмите **Конвертировать**. Результат появится рядом с исходником: `document.pdf` → `document.md`. Картинки — в `document_images`.
5. После завершения полоска прогресса исчезнет и появятся **Открыть результат** и **Открыть папку**. Первая кнопка открывает `.md` в приложении, выбранном в Windows, вторая — папку результата. Для переноса результата вместе с картинками скопируйте и файл, и папку изображений.

Если `.md` уже существует, окно предлагает перезаписать его, сохранить рядом с суффиксом `_1` или отменить операцию. Кнопка **Отмена** останавливает текущую обработку. Исходный документ программа не заменяет.

## Возможности

- PDF: заголовки, списки, таблицы в рамках, картинки; отдельный OCR-движок для сканов.
- Word: таблицы, изображения, примечания и поддерживаемые формулы в LaTeX.
- Excel: один выбранный лист, объединённые ячейки, примечания, изображения и широкие таблицы с сохранением позиции данных.
- CSV/TSV/TXT: определение кодировки; для CSV — определение разделителя.
- Прогресс обработки, отмена, журнал и защита от случайной перезаписи исходника.
- **Настройки → Язык → Русский / English**, без перезапуска. Сохраняются язык, движок, флажки и последняя папка.

## Движки PDF

| Движок | Подходит для | Ограничения |
| --- | --- | --- |
| `auto` | Обычная работа: Structured для текста; Marker для обнаруженных страниц-сканов, если установлен | Выбор эвристический; сложный результат нужно проверить |
| `structured` | Мануалы и книги с текстовым слоем, таблицы в рамках | Нет OCR; таблицы без рамок и сложные формулы могут потерять структуру |
| `marker` | Сканы, сложная вёрстка, формулы и таблицы без рамок | Требует загрузки моделей; может ошибаться в числах и объединять таблицы; медленный на CPU |
| `pymupdf` | Быстрое извлечение обычного текста | Не сохраняет структуру таблиц и картинки; не распознаёт сканы |

«Авто» проверяет все страницы, включая смешанные PDF. Повторяющиеся прозрачные фоны разделителей не считаются сканами. Если Marker отсутствует, программа предупреждает о возможном отсутствии текста на сканах.

## Marker

Нажмите **Установить Marker…**, выберите **CPU** или **NVIDIA CUDA 12.6** и папку. Для CUDA нужен совместимый драйвер NVIDIA. Загрузка занимает несколько гигабайт; для установки и моделей нужен интернет. После загрузки обработка выполняется локально.

На CPU сложный PDF может обрабатываться около минуты на страницу; первый запуск дополнительно загружает модели. Время зависит от числа страниц, вёрстки, OCR и оборудования, а не только от размера файла.

## Настройки и файлы

Установщик по умолчанию устанавливает программу для всех пользователей в Program Files. Для установки только текущему пользователю используйте параметр `/CURRENTUSER`. Удаление доступно через «Приложения» Windows.

Лёгкая portable-сборка не требует установки. Как и установленная версия, она хранит настройки и журнал в `%LOCALAPPDATA%\PDF2MD`, а загруженный Marker — в выбранной папке, по умолчанию `C:\ProgramData\PDF2MD`. Это не полностью изолированный профиль на флешке: настройки и Marker не переносятся автоматически вместе с ZIP.

Удаление программы сохраняет документы, настройки и отдельно загруженные модели. Подробнее — [FAQ](FAQ.md) и [приватность](PRIVACY.md).

## Ограничения

Проверяйте важные таблицы, числа и формулы по исходнику. Колонтитулы Word не экспортируются. Значения формул Excel берутся из сохранённого кэша: если его нет, откройте и сохраните книгу в Excel. Числа выводятся в русском формате независимо от языка интерфейса.

Пакетная обработка и экспорт всех листов книги за один запуск пока не поддерживаются. Системное окно выбора файла использует язык Windows; диагностические сообщения сторонних библиотек могут оставаться на их языке. Широким HTML-таблицам нужен совместимый просмотрщик.
