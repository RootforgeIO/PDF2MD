# PDF2MD 0.2.0

Локальная конвертация PDF, Word, Excel, CSV, TSV и TXT в Markdown. Windows 10 (1809+) / Windows 11 x64.

Подготавливает документы для работы с ИИ, чтобы сократить расход токенов на их обработку. Экономия зависит от документа и ИИ-сервиса.

## Что нового

- Полный русский и английский интерфейс с выбором языка в меню.
- Сохранение настроек и последней папки.
- «Авто» предпочитает Structured для текста и использует доступный Marker для сканов.
- Защита исходных файлов и атомарная запись Markdown.
- Исправления запуска, перетаскивания и отмены; монотонный прогресс Marker.
- Ярлык на рабочем столе создаётся автоматически при установке.

## Файлы

- `PDF2MD-0.2.0-setup.exe` — установщик.
- `PDF2MD-0.2.0-portable.zip` — запуск без установки, Python включён.
- `PDF2MD-0.2.0-source.zip` — исходники.
- `SHA256SUMS.txt` — контрольные суммы.
- `release-manifest.json` — версия, состав и сведения о сборках.

Marker и его модели не входят в лёгкие сборки: их можно установить из приложения. Настройки и отдельно загруженный Marker не переносятся вместе с portable-архивом. Для старых форматов Office нужны Word/Excel. Сборки без цифровой подписи.

Пройдены 61 регрессионный тест, проверки GUI на двух языках, конвертации PDF/Word/Excel, настройки и перетаскивание. Проверены установка и удаление `/CURRENTUSER`, а также обновление с 0.1.0 с сохранением настроек. Интерактивная установка с UAC для всех пользователей отдельно не проверялась.

## English

Local PDF, Word, Excel, CSV, TSV and TXT conversion to Markdown. Windows 10 (1809+) / Windows 11 x64.

Prepares documents for AI workflows to help reduce token usage. Savings depend on the document and AI service.

This version adds Russian/English language selection, persistent settings, content-aware Auto selection, source protection and atomic Markdown output. It fixes startup and drag-and-drop fallback, Marker cancellation and progress. The installer creates Desktop and Start menu shortcuts automatically.

Choose the installer or extract the portable ZIP completely. Python is included; Marker and its models are optional downloads. Settings and separately installed Marker files are not moved with the portable archive. Legacy Office formats require Word/Excel. Builds are unsigned.

Validation includes 61 regression tests, both UI languages, PDF/Word/Excel conversion, preferences, drag-and-drop, per-user installation/uninstall and upgrade from 0.1.0. Interactive all-users installation through UAC was not separately tested.
