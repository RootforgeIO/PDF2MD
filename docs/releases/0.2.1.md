# PDF2MD 0.2.1

Локальная конвертация документов в Markdown для работы с ИИ и сокращения расхода токенов. Экономия зависит от документа и сервиса. Windows 10 (1809+) / Windows 11 x64.

После успешной конвертации полоска прогресса исчезает. Появляются «Открыть результат» и «Открыть папку», а статус показывает имя сохранённого файла. Окно остаётся готовым к следующей конвертации. Повторное название на синей полосе убрано; внизу добавлена ссылка на GitHub RootforgeIO.

Файлы: `PDF2MD-0.2.1-setup.exe`, `PDF2MD-0.2.1-portable.zip`, `PDF2MD-0.2.1-source.zip`, `SHA256SUMS.txt`, `release-manifest.json`.

Python включён. Marker и модели в публичных сборках скачиваются отдельно из приложения. Сборки без цифровой подписи. Установщик автоматически создаёт ярлык на рабочем столе. Для открытия Markdown нужна выбранная в Windows программа; можно открыть папку результата и выбрать просмотрщик.

## English

Local document-to-Markdown conversion for AI workflows and reduced token usage. Savings depend on the document and service. Windows 10 (1809+) / Windows 11 x64.

Successful conversion now replaces the progress bar with “Open result” and “Open folder” and shows the saved filename. The window stays ready for another conversion. The repeated title has been removed from the blue band; the footer now links to RootforgeIO on GitHub.

Choose the installer or portable ZIP; Python is included. Marker and its models are optional downloads in public builds. Builds are unsigned. Setup automatically creates a desktop shortcut. Opening Markdown requires a default application in Windows; use “Open folder” to choose a viewer.
